# AI Player · 智能伴学播放器

AI Player 是面向本地视频课程的桌面学习工具，集成视频播放、Markdown 笔记、逐字稿与 AI 导学，支持按时间点回溯内容并制定个性化学习计划。应用仅提供桌面客户端（macOS、Windows、Linux），不支持在浏览器中单独运行。

## 功能

- **本地课程管理**：打开课程文件夹后按章节展示视频，自动记录观看进度，支持倍速播放与快捷键操作。
- **视频联动笔记**：支持 Markdown、代码块与数学公式，可插入时间戳和视频截图，点击时间戳即可跳转回看。
- **逐字稿**：读取同名 SRT / VTT 字幕，或在本机离线转写视频；支持逐句跳转、本节关键词检索和引用至笔记。
- **AI 定制路线**：根据已有基础、学习目标和每日可用时间推荐必修与选修课节，跳过已掌握内容并保留必要的前置课程。
- **疑问回溯**：记录学习中的疑问并查找相关基础课；存在字幕时可定位到具体片段，回看后返回原课程位置。
- **学习安排与练习**：生成今日安排、提示学习片段结束、记录每日打卡；根据字幕与笔记生成课后练习并记录知识掌握程度。

## 系统要求

- macOS 13.5 及以上、Windows 10 及以上，或受 Tauri 2 支持的 Linux 发行版。
- 安装包已内置转写运行环境（Node.js、FFmpeg 与 SenseVoice 引擎），无需另行安装依赖或启动服务。

## 数据存储

| 数据 | 位置 |
| --- | --- |
| 最近课程、课程位置、观看进度、笔记、导学路线、疑问、练习、打卡、AI 配置 | 客户端数据目录中的 SQLite 数据库 `ai-player.db` |
| 视频、字幕（含转写生成的 `.srt`）、笔记副本（同名 `.md` 与 `.assets` 截图目录） | 课程文件夹 |
| 语音识别模型 | 首次转写时下载至客户端数据目录，可离线复用 |

客户端仅能读写用户选择的课程文件夹，写入范围限于笔记、字幕和图片文件。

## 使用说明

### 导入课程与记录笔记

1. 点击 **打开课程文件夹** 并选择视频所在目录，子文件夹按章节展示。
2. 在 **课程概览** 查看学习进度与安排，进入 **播放器** 选择课节并记录笔记，可插入时间戳、截图或记录疑问。
3. 通过首页 **最近打开** 继续学习，课程位置与播放进度自动保存。课程文件夹移动后，按提示重新关联原文件夹即可恢复全部学习记录。

支持 MP4、WebM、MKV、MOV 等常见格式，能否播放取决于系统对视频编码的支持。点击全屏按钮、双击视频或按 `F` 切换全屏，按 `Esc` 退出。

### AI 导学（可选）

1. 打开 **AI 导学 → AI 设置**，填写配置名称、兼容 OpenAI 的服务地址、模型名称和 API 密钥，点击 **保存并使用**。可保存多组配置并通过 **当前使用的 AI** 切换，导学与课后练习共用所选配置。本机 Ollama 可使用 `http://localhost:11434/v1`，未启用鉴权时密钥留空。
2. 在 **定制路线** 中填写已有基础、学习目标和每日可用时间，生成路线后点击 **开始学习**。
3. 学习过程中可通过 **今日学习与打卡** 安排进度，在笔记中点击 **查找基础课** 回看相关课程，或通过 **课后练习** 检验学习效果。

AI 功能会将课程标题、笔记、字幕或作答内容发送至所配置的服务，视频与截图不会上传。

### 逐字稿（可选）

视频旁存在同名 `.srt` / `.vtt` 文件时，切换至 **逐字稿** 页签即可查看。

打开 **逐字稿** 页签后，客户端自动启动内置转写服务。首次使用需下载语音模型并显示进度，完成后可离线转写。面板中可停止或重新准备服务；转写任务在切换页面后继续执行，并支持查看进度与取消。退出客户端时内置服务随之关闭。

点击句子可跳转播放，也可检索关键词或将原句引用至笔记。

## 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 5 秒 |
| `[` / `]` | 减速 / 加速 |
| `Alt + T` | 插入当前时间戳 |
| `Alt + S` | 截图至笔记 |
| `Ctrl + S` / `⌘ + S` | 保存笔记 |
| `?` | 查看全部快捷键 |

macOS 上 `Alt` 对应 `Option（⌥）`。在笔记或输入框中输入时，播放类快捷键不生效。

## 开发

开发与构建需要 Node.js 24 LTS（官方发行版）、Rust 1.88 及以上，以及对应平台的 Tauri 2 开发环境。

```bash
npm install
npm run desktop:dev      # 启动桌面客户端（开发模式）
npm run desktop:build    # 生成当前平台的安装包
```

安装包输出至 `src-tauri/target/release/bundle/`，各平台需在对应系统上构建。

### 测试

```bash
npm run typecheck        # 前端类型检查
npm test                 # 单元测试（含 SQLite 数据层）
npm run desktop:test     # Rust 端测试（数据库、文件访问范围）
npm run test:e2e         # 界面端到端测试
```

端到端测试在 Vite 开发服务器上运行前端，并在页面中注入 Tauri IPC：原生命令由 `tests/browser/desktop.ts` 处理，学习数据写入临时 SQLite 数据库，课程文件位于临时目录。该实现与 `src-tauri/src/db.rs`、`files.rs` 的行为保持一致，修改 Rust 端数据接口时需同步更新。
