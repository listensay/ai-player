# AI Player

面向本地视频课程的桌面学习工具，集成课程播放、Markdown 笔记、离线语音转写、AI 导学与学习计划管理。

应用基于 Tauri 2，课程文件和学习记录保存在本地。前端依赖桌面端的文件访问与数据库能力，不支持作为独立网页运行。

## 功能

| 模块 | 功能 |
| --- | --- |
| 今日首页与课程管理 | 跨课程今日安排、继续播放、投入汇总，课程搜索、置顶、暂停和归档；打开本地文件夹及重新关联移动后的目录 |
| 学习管理 | 全局定时提醒，可按需关联课程，支持 Mac 提醒同步状态、更新、停用与删除 |
| 视频播放 | 进度恢复、倍速、全屏、快捷键、课节切换与学习片段结束提醒 |
| Playbo 桌宠 | 专注、休息与完成状态反馈；支持软件内悬浮桌宠和透明桌面挂件 |
| 课程笔记 | Markdown 编辑、时间戳跳转、视频截图、字幕引用与自动保存 |
| 逐字稿与知识点 | 打开视频自动读取字幕或本地转写，AI 生成整课概览与主题要点，在右侧知识点页签显示并缓存 |
| AI 导学 | 根据学习背景与目标生成路线，展示知识结构和前置关系 |
| 学习计划 | 每周学习日、工作日与周末预算、当天减量或休息、暂停恢复、顺延或保留截止日期，调整预览与撤销 |
| 进度与回顾 | 每日任务、阶段目标、实践与验收、打卡月历、跨课程周回顾和历史任务明细 |
| 课后练习与每日练习 | 按知识点生成多题，当天计划视频学完后弹出“今日巩固”，保存作答与反馈 |

观看进度、任务完成状态和知识掌握程度独立记录。视频播放完成或练习答对，不会自动将知识点标记为已掌握。

## 开发与构建

### 环境要求

- **Node.js 24 LTS 官方发行版**与 npm。运行环境打包脚本会校验 Node 主版本；macOS 下还会拒绝依赖非系统动态库的 Node 发行版。
- **Rust 1.88 或更高版本**，包含 Cargo。
- 当前系统所需的 [Tauri 2 开发依赖](https://v2.tauri.app/start/prerequisites/)，例如 macOS 的 Xcode Command Line Tools、Windows 的 C++ 构建工具与 WebView2。
- macOS 安装包的最低系统版本配置为 **13.5**。其他平台需在对应系统上安装开发依赖并验证构建。

桌面包包含 Node、FFmpeg 和 sherpa-onnx 原生依赖，应在目标操作系统及 CPU 架构上构建。

### 启动

在项目根目录执行：

```bash
npm ci
npm run dev
```

启动时会准备本地转写运行环境，再启动 Vite 和 Tauri 窗口。开发服务使用 `127.0.0.1:1420`；应通过桌面窗口验证功能，直接访问该地址只会显示桌面客户端提示。

运行环境按 Node 版本、平台、架构和依赖版本复用已准备文件，仅同步变化的文件；缺失或被修改的输出会自动修复，旧依赖文件随同步清理。不变的文件与清单保持原修改时间，避免重复复制 Node 和 FFmpeg。

应用数据库统一保存在应用数据目录下的 `ai-player.db`。若需在开发时隔离调试数据，可设置环境变量 `AI_PLAYER_DEV_ISOLATE=1`。

### 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动桌面开发模式 |

| `npm run build` | 执行 TypeScript / Vue 类型检查并构建前端 |
| `npm test` | 验证笔记读写与切课、按需加载、AI 分批续跑、学习计划、每日巩固与练习 |
| `npm run check` | 执行自动化测试、类型检查和前端构建 |

| `npm run desktop:frontend` | 准备转写运行环境并构建前端，不执行类型检查 |
| `npm run desktop:webdev` | 准备转写运行环境并启动 Vite，由 Tauri 开发流程调用 |
| `cargo check --manifest-path src-tauri/Cargo.toml` | 检查 Rust 代码 |
| `cargo test --manifest-path src-tauri/Cargo.toml` | 验证数据库兼容、课程库、计划快照与原生逻辑 |

打包前先执行类型检查与前端构建：

```bash
npm run build
npm run desktop:build
```

默认前端产物位于 `dist/`，桌面安装包位于 Cargo 目标目录的 `release/bundle/`；按当前 SSD 配置为 `/Volumes/Fake/release/bundle/`。`src-tauri/runtime/` 由脚本生成，不应手动维护或提交。

自动化链路覆盖和隔离桌面回归步骤见 [学习链路验证](docs/testing.md)。CI 在 macOS 执行测试、前端检查、Rust 测试与桌面构建。

磁盘空间较小时，日常界面开发优先使用 `npm run dev` 的热更新，不要每次都打发布包。仓库 `.cargo/config.toml` 将 `build.target-dir` 设置为 `/Volumes/Fake`（对应 `CARGO_TARGET_DIR` 的构建目录设置），保留 Cargo 默认的调试信息和增量编译行为；显式设置的 `CARGO_TARGET_DIR` 环境变量优先。外置卷需挂载后再构建。只需检查前端时使用 `npm run build`，不产生 Rust 编译缓存。清理时仅处理专用的编译产物；当前目标目录为外置卷根目录，不要删除整个 `/Volumes/Fake`。保留 `src-tauri/src/`、Cargo 配置及其他源码；清缓存后首次构建需要重新编译。

顶部「设置」通过右侧导航切换等宽的桌宠设置和 AI 服务设置，统一管理 AI 服务配置与「启动时自动打开桌宠」。AI 服务设置可用「测试连接」验证当前表单的服务、密钥和模型 JSON 响应，支持取消与 30 秒超时；测试仅发送固定简短请求，不保存配置或发送课程资料。保存、删除及测试结果以可关闭的弹出提示显示。自动打开默认关闭，设置保存到本地数据库，下次启动生效；仍可从顶部手动打开桌面挂件。学习管理中的提醒时间通过 24 小时时间选择器选择并确认。当天有有效观看或已记录实践时间后，该课程的应用内提醒与应用发送的系统通知停止，并取消稍后提醒；通用提醒在任一课程开始学习后停止，次日恢复。Mac 提醒事项独立排程。


## 使用

### 打开课程

在首页选择课程文件夹，子文件夹会作为章节展示。文件名按自然顺序排序，例如 `2.mp4` 排在 `10.mp4` 前面。

应用识别 MP4、WebM、MKV、MOV 等常见视频扩展名，实际播放能力取决于系统 WebView 和视频编码。遇到编码不兼容时，可转为 H.264 视频与 AAC 音频的 MP4 文件。

课程目录示例：

```text
课程/
└── 第一章/
    ├── 01-入门.mp4
    ├── 01-入门.srt
    ├── 01-入门.md
    └── 01-入门.assets/
```

字幕与视频放在同一目录，文件名去掉扩展名后保持一致。笔记与图片以 SQLite 为主要存储，并尝试将 Markdown 副本与图片同步到课程目录；目录不可写时，副本可能无法生成。

### 课程笔记

视频详情右侧按“笔记、知识点、逐字稿”排列，进入或切换课节时默认选中笔记。笔记编辑器在进入播放器后按需加载，也支持时间戳、截图、字幕引用及保存快捷键触发加载。切换右侧页签保留编辑状态。读取失败时显示重试入口，不会将空内容或旧 Markdown 副本覆盖到数据库；只有数据库中尚无笔记时才导入副本，主动清空的笔记保持为空。

自动保存按顺序处理修改，切课、离开播放器和关闭窗口会等待保存完成；主存储失败时保留当前页面与草稿。课程目录副本同步失败单独提示，可重试同步，已保存到数据库的内容仍然有效。

新截图和上传图片使用独立图片记录，Markdown 正文仅保存图片路径；同一时间点的多张截图使用不同文件名。旧版内嵌 Base64 图片继续可读，不自动改写旧笔记。编辑时仅在正文变化后进行一次 Markdown 序列化。

播放进度读取失败时暂停进度修改，可从顶部错误提示重试。写入失败保留待保存记录并自动退避重试，成功后才清除；关闭窗口会等待进度写入，保存失败时保留窗口。

### Playbo 桌宠

桌宠仅作为独立桌面挂件显示，可从顶部「桌面挂件」按钮打开，程序内不再嵌入桌宠。独立挂件保持置顶，可拖动位置，单击摸摸会短暂回应并摇摆，双击播放或暂停；右键（或 Shift+F10）打开快捷菜单，可休息 3 分钟、延后关怀提醒、隐藏日常提示、回到课程或关闭挂件。对话气泡始终只显示一条文字；隐藏日常提示不影响关怀和错误提示。播放器全屏时隐藏，退出后恢复。有效播放 25 分钟显示专注状态；60 分钟后提示休息。倍速按实际时间计时，暂停、缓冲、拖动进度和电脑休眠不计入；休息满 3 分钟后重新计时。重启应用后重新开始本次计时。

状态面板提供 **休息 3 分钟** 和 **稍后提醒**。完成计划课节、今日巩固或当日学习打卡时显示完成星标。读取历史记录不会重复触发；系统开启“减少动态效果”时使用静态形象。

点击顶部 **桌面挂件**，打开透明、无标题栏、始终置顶的独立窗口，点击主软件不会遮挡挂件。窗口收紧到 280 × 400，机器人和可见操作以外的透明区域支持点击穿透。气泡在机器人头顶居中并靠近头部，只显示一条文字，也不拦截鼠标；更多操作通过右键菜单使用；关闭挂件不会停止播放，关闭主应用会一并退出挂件。播放器全屏时隐藏挂件，退出后恢复置顶。

主窗口离开播放器页面时，课程按原有规则暂停，挂件控制同步禁用。macOS 14 及以上已禁用主播放器在后台被 WebView 挂起；无音轨视频在最小化时仍可能被系统暂停，可点击挂件中的“继续学习”。其他系统的后台播放能力取决于系统 WebView。

### 配置 AI

进入课程后，打开 **AI 导学 → AI 设置**，添加服务配置并选择“保存并使用”。支持多组配置，切换配置仅影响新请求。

| 字段 | 说明 |
| --- | --- |
| 配置名称 | 用于区分服务或使用场景 |
| 接口格式 | OpenAI 兼容或 Anthropic；已有配置默认使用 OpenAI 兼容格式 |
| 服务地址 | OpenAI 兼容服务例如 `https://api.example.com/v1`，自动补全 `/chat/completions`；Anthropic 官方地址为 `https://api.anthropic.com/v1`，自动补全 `/messages`，也支持完整接口地址 |
| 模型名称 | 服务实际支持的模型标识，模型需能按要求返回完整 JSON |
| 模型上下文 | Anthropic 可选择“默认”或“1M（100 万 token）”；已有配置使用默认值，需所选模型和服务支持 |
| API 密钥 | 服务要求的密钥；无需认证的本地服务可留空 |
| 响应时限 | 默认 15 分钟，可设置为 1–30 分钟 |

远程服务必须使用 HTTPS；`localhost`、`127.0.0.1` 和 `[::1]` 可使用 HTTP。本地 Ollama 的兼容地址可填写 `http://localhost:11434/v1`，模型需事先安装。

直接使用 Claude 时，选择 **Anthropic**，填写上述官方地址、账户可用的模型标识和 Anthropic API 密钥，再选择“保存并使用”。也支持提供 Anthropic Messages 格式的兼容服务。请求使用 `x-api-key`、`anthropic-version: 2023-06-01` 和顶层 `system`；返回的文本块合并后沿用原有 JSON 与业务校验。输出被截断或返回无效内容时会报错，不应用该响应。

选择 1M 时，Anthropic 请求附带 `anthropic-beta: context-1m-2025-08-07`；默认不附带此头，OpenAI 兼容请求也不发送。原生已支持 1M 的模型在默认选项下即可使用其容量；该选项用于显式请求兼容服务的长上下文支持，不会扩大模型本身的容量或改变材料分批规则。

输出长度不再提供配置，旧配置中的 `maxTokens` 会被忽略，并在下次保存配置时移除。OpenAI 兼容请求使用服务默认值；Anthropic Messages 协议必填的 `max_tokens` 由程序内部设为 4096，与输入上下文容量无关。

AI 配置与密钥保存在本地 SQLite 中。打开视频后，逐字稿会自动发送至所选 AI 服务整理知识点；使用其他 AI 功能时，相关课程信息、笔记或作答也会发送至所选服务。视频与截图不会作为 AI 请求材料上传。练习材料可能包含尚未保存的笔记文字，发送内容可在练习面板中预览。选择题和判断题在本地核对，其他题型通过所选 AI 评估。

### 课后练习

默认按知识点总结生成一组 3 道题，可在“材料与设置”选择每组 3、5 或 8 题，也可通过“继续出题”菜单再练一题或一组。保留笔记和补充材料作为额外依据；可切换历史记录或使用上一题 / 下一题回看。材料较多时按每批最多 12000 字分组出题，所有批次通过校验后一起保存，不会只考开头的内容。

题目与反馈分别在“作答”和“反馈解析”中阅读，切换控件采用白底与黄色选中胶囊，提交后自动显示反馈。反馈按需要调整、已答对和下一步分区，可返回修改答案；参考答案与知识点要求可展开查看。

每个课节独立保留最近 20 道练习，每题最多反馈 3 次；重复提交未修改的答案不会占用次数。新题会参考本课已有题目以减少重复，题干与选项重复的结果不会保存。练习记录读取失败时暂停生成与保存，避免覆盖原有数据，关闭后重新打开可重试。

知识点整理、分批出题和逐字稿 AI 校对会保存已完成的批次。失败后再次执行会复用同一材料与服务配置下的进度，重启后仍可续跑；修改材料、模型或服务会使用新的任务。知识点可选择“从头整理”；最终总结或字幕文件写入失败时，重试复用已有 AI 结果。练习整组通过校验后才加入记录，字幕全部校对成功并写入文件后才更新显示。

字幕校对要求每个输入句子恰好返回一条有效结果，漏句、重复或无效文本会保留该批次待重试。旧缓存中的残缺批次会重新校验，仅重做未通过的部分。最终结果保存成功后，批次缓存保留 30 天；未完成或尚未确认最终保存的记录继续保留。清理在应用启动和任务完成时执行，不删除已保存的知识点、练习或字幕。

逐字稿内存缓存按最近使用顺序控制在 12 个课节、合计约 600 万文本字符以内。当前课节、读写和转写中的任务，以及尚未保存的失败结果不会被淘汰；这些受保护内容可暂时超过上限。再次打开已释放的课节会从字幕文件读取。

### 知识点与今日巩固

打开视频后优先使用同名字幕，没有字幕时自动启动本地转写。逐字稿就绪后自动交给所选 AI 整理整课总结；播放器右侧“知识点”页签展示本课概览和按主题归纳的核心要点，不提供时间戳或片段回看入口。长逐字稿先完整分批提炼，再合并跨片段的重复概念与联系；材料过长时逐层合并，最终形成一份整课总结。提炼与合并都支持失败续跑，未完成时不展示拼接的片段结果。总结按课程、课节与逐字稿内容缓存，旧版片段缓存会在成功生成新版后替换；未配置 AI 或请求失败时显示设置或重试入口。取消不会覆盖已有总结。

当天所有计划内的视频学习、补学片段完成后自动弹出“今日巩固”，默认生成 5 道题。连续播放跨过计划终点会标记对应视频任务完成，拖动进度条不触发；也可手动勾选完成。实践任务不阻塞视频巩固，没有视频任务时不触发。当天片段另行归纳为出题材料，与播放器的整课总结分开缓存，片段外的内容不会提前考查。

自动提醒每天一次；可关闭弹窗，在概览、播放器或今日学习安排中继续。题目、草稿与反馈按课程、日期和计划范围隔离保存，调整计划范围会创建新的练习，旧记录保留在本地。所有题目提交后显示完成状态与正确题数；作答结果不自动修改知识掌握程度。知识点缓存、每日练习及提醒记录复用 SQLite 的设置存储。

### 本地转写

打开视频需要转写时，桌面端会启动并管理转写服务。识别使用 FFmpeg、sherpa-onnx、SenseVoice 和 Silero VAD，支持中文、英文、日文、韩文和粤语。

首次使用需联网下载语音模型，模型就绪后可离线转写，无需配置 AI 服务。任务可在切换课节后继续运行，完成后写入视频同名 `.srt` 文件；重新转写完成后会覆盖该文件。支持在逐字稿就绪后使用 AI 进行文本校对与术语纠错，校对结果会写回同名 `.srt` 文件。

模型默认从 [sherpa-onnx 模型发布页](https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models)下载，也可手动将以下文件放入应用数据目录的 `models/`：

```text
models/
├── silero_vad.onnx
└── sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17/
    ├── model.int8.onnx
    └── tokens.txt
```

开发时可通过环境变量 `AI_PLAYER_MODEL_BASE_URL` 指定模型镜像地址。镜像需提供 `silero_vad.onnx` 和 `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17.tar.bz2`。桌面端会自行指定模型目录、动态端口和访问令牌，无需手动启动 `asr-server/`。

### 今日首页与周回顾

已有课程时，首页展示“继续学习”、跨课程“今日安排”、今日投入与“我的课程”。点击继续播放会回到上次课节和位置；今日安排可直接播放指定片段，进入实践记录或今日巩固。首次使用仍从打开课程文件夹开始。

课程支持搜索、置顶、暂停、归档和恢复。暂停或归档后不再新增每日任务，学习记录仍参与历史回顾。课程库独立保留课程身份，不受最近打开列表的 20 条限制影响；已移动目录仍可重新关联。

每日可用时间用于提示多门课程的总预算是否超出，设为 0 时不作比较。各课程继续使用各自的计划，不自动分配课程之间的时间。

周回顾汇总有效观看与已记录实践，可切换周、点击日期、展开课程查看任务明细。计划快照从使用新功能后开始记录；旧日期只有实际投入时，不补造历史任务完成率。视频观看、每日任务、知识掌握与阶段验收保持独立，预计观看结束日期按 1 倍速估算，不代表实践或验收完成。

### 学习提醒

点击顶部 **学习管理**，统一设置学习提醒，无需先打开课程。

- **软件内提醒**：设置内容、时间、重复星期和可选的关联课程，可启用或停用。软件运行时按本地时间检查，当天错过的提醒会在打开软件时补发一次；关闭软件后不发送软件内提醒。提醒可直接进入学习、关闭或延后 10 分钟，延后时间和当日发送记录在重启后保留。关联课程暂停或归档时暂停软件内提醒。
- **Mac 提醒事项**：保存提醒后，点击卡片上的“添加到 Mac 提醒事项”，核对内容后确认。首次使用需要允许访问提醒事项；拒绝后可在系统设置的“隐私与安全性 → 提醒事项”中授权。应用使用 EventKit 将标题、下次到期时间、按星期重复规则和到期通知写入“AI Player”列表，关闭软件后仍由系统提醒。重复事项遵循系统规则，完成当前事项后生成下一次。记录上次同步内容，显示“已添加”“修改后待更新”“停用待同步”“已同步停用”等状态。编辑或切换启用状态后提供同步确认；取消或同步失败时保留待处理状态。关联课程暂停或归档也会显示待同步停用。停用同步会清除系统事项的到期时间、通知和重复规则，保留事项，重新启用后可同步恢复。删除时可同时删除未完成的系统事项，已完成历史保留；仅删除本地时在待处理列表保留系统删除入口。同步状态基于最近一次成功写入，不自动读取或导入 Mac 中的手动修改。该功能仅在 macOS 显示。
- **系统通知**：在提醒页开启“同时发送系统通知”，按系统提示授权。未开启或未获授权时仍显示软件内提醒；系统的勿扰模式等设置可能影响通知显示。

在 **Mac 提醒事项**中点击事项的链接，即可启动或唤起 AI Player，打开提醒当前关联的课程播放器，沿用上次课节与观看位置；已完成课节沿用播放器从头打开的规则。重复点击当前正在查看的课程不会重新加载视频或回退位置。没有关联课程、提醒已删除或课程记录已不存在时进入学习管理；课程目录不可用时提供重新关联入口。点击通知本身通常先打开 Mac 提醒事项，再点击事项链接进入课程。旧版已导出的提醒沿用同一链接，无需重新添加。打开链接不自动恢复暂停课程，也不更改系统提醒的完成状态。

链接仅携带提醒编号（`aiplayer-study://reminder/<id>`），目标课程从本地记录解析，不接受外部文件路径或播放时间。切换前保存当前笔记和播放进度，保存失败时保留当前页面并提供“重试打开”。

这些设置保存在本地 SQLite 的 `app_settings` 中（`study-tools`，Mac 关联记录为 `mac-reminders-links`），不需要 AI 服务。数据读取或校验失败时暂停写入，不覆盖原始记录。Mac 权限说明随 `src-tauri/Info.plist` 打包，支持 macOS 13 的提醒权限与 macOS 14 及以上的完整访问权限。

### 学习计划与打卡

在课程概览或今日安排中选择“设置学习计划 / 调整计划”。未生成 AI 路线时，也可按课程原顺序创建本地学习计划；需要定制路线时，再填写学习背景与目标。完整计划支持周期、每日时间分配、复盘日和阶段实践。

在“学习计划”或“今日学习”中点击 **顺延未完成安排**，即可预览把今日剩余安排移至下个学习日；选择 **临时休息** 并指定恢复日期，可一次安排多天休息并顺延。按现有每日投入、每周学习日和原定休息日计算，积压课节会补足预计观看时间，未完成的后续阶段与计划结束日期一起移动。预览显示下次学习日、预计看完视频的日期及结束日期，确认后应用；不更改课程顺序、已完成阶段、观看进度、实践证据和验收记录，可撤销最近一次调整。计划周期上限仍为 1095 天，无可用学习时间时会提示先调整安排。

调整计划支持每周学习日、工作日与周末预算、当天临时减量或休息、暂停至指定日期或手动恢复，以及顺延阶段和结束日期。保留结束日期时只在每日总投入上限内增加观看预算，时间不足会提示缺口。已有阶段的工作日专属预算继续生效，临时日期预算优先于每周安排。

应用前可预览今日剩余任务、未来七天预算、预计视频完成日期与阶段日期变化。定时暂停到期后恢复原排期，可另行顺延；手动恢复时可选择顺延或保留截止日期。调整与撤销只改变安排，保留实际观看、实践投入和证据、知识掌握与验收记录；重启后仍可撤销最近一次安排调整。休息日不生成新的学习目标，也不撤销已经达成的打卡。

打卡按有效观看时长计算；设置完整学习计划后，还会计入已记录的实践时间。倍速播放按实际经过的时间计时，暂停、缓冲和跳转不计入。视频片段可在连续播放到计划终点时自动完成，也可手动标记；实践任务和阶段验收分别记录，阶段验收需填写成果证据。

## 数据与目录

应用数据使用 Tauri 的 `app_data_dir`，应用标识为 `app.aiplayer.desktop`。常见位置如下：

| 系统 | 数据目录 |
| --- | --- |
| macOS | `~/Library/Application Support/app.aiplayer.desktop/` |
| Windows | `%APPDATA%\app.aiplayer.desktop\` |
| Linux | `$XDG_DATA_HOME/app.aiplayer.desktop/`，未设置时通常为 `~/.local/share/app.aiplayer.desktop/` |

其中 `ai-player.db` 保存课程位置、进度、笔记、图片、导学、练习、打卡和设置；`models/` 保存转写模型；`asr.log` 保存转写服务日志。数据库包含 AI 密钥，分享项目或排查问题时不要提交该目录。备份时先退出应用，再备份应用数据目录及原课程文件夹。

导学读取或校验失败时暂停保存，避免空状态覆盖原有路线。路线或知识掌握发生变更时，数据库保留每课最近 20 个导学版本；扫描视频信息不会占用这些版本。学习时长只累计，旧窗口的记录不能回退时长或撤销已有打卡。

`course_library` 保存课程状态与置顶信息，兼容已有最近课程；`daily_plan_snapshots` 按课程和日期保存最初预算、当前预算及任务状态，拒绝较旧快照覆盖新快照。每周规则、日期例外、暂停状态及可撤销的安排继续保存在现有计划和实践记录中。首页只读取本地学习记录，不主动扫描视频或启动 AI 请求；单门课程读取失败时独立提示，并暂时从汇总排除。

```text
app/
├── components/       界面组件
├── pages/            首页、课程概览和播放器页面
├── composables/      播放、课程、导学、练习等状态与流程
├── utils/            数据访问、AI 请求、校验与业务计算
├── types/            业务类型和文件接口
├── milkdown/         笔记编辑器扩展
└── styles/           主题与组件样式
asr-server/           本地音频解码、模型管理和识别服务
scripts/              桌面转写运行环境准备与前端启动脚本
src-tauri/
├── src/              Rust 原生命令、文件访问、SQLite 和转写进程管理
├── capabilities/     桌面权限配置
└── tauri.conf.json   桌面窗口与打包配置
DESIGN.md             视觉参考与组件约定
```

前端使用 Vue 3、TypeScript、Vite、Vuetify 3、Tailwind CSS 4 和 Milkdown；桌面端使用 Tauri 2、Rust 与 SQLite。

## AI 协作规范

本节面向参与本项目开发的 AI 编程助手。开始修改前阅读本文件、相关源码与 [DESIGN.md](DESIGN.md)，以当前任务要求和实际实现为依据。

**禁止 AI 修改 `DESIGN.md`。该文件仅供只读参考，不得新增、删除、改写、翻译或格式化其中的内容。**

### 修改范围

- 先确认现有实现和工作区改动，保留用户未提交的内容。围绕当前任务修改，不附带无关重构、依赖升级或格式化。
- 常规、可逆且已授权的工作直接完成；信息不影响实现时，采用与项目一致的合理默认值。
- 保持 Tauri 桌面架构，不为预览方便引入浏览器运行模式、模拟原生接口或新的后端服务。
- 功能、启动命令、配置、存储方式或项目视觉约定变化时，同步更新本文件。

### 代码与组件

- 使用 Vue 3 Composition API、`<script setup lang="ts">` 和现有 TypeScript 类型。界面放在组件中，状态与流程放在 composables，校验和纯计算放在 utils。
- 复用 `UiButton`、`AppIcon`、`PracticeText` 等已有组件，图标统一使用现有 Lucide 接入方式。
- 文本、数字、选择、文件和滑块控件使用 Vuetify，不另写原生表单控件替代现有体系。折叠内容使用 `VExpansionPanels`，弹窗使用 `VDialog`。
- 样式沿用主题变量与现有布局，页面保持奶油色背景、深色文字、黄色重点和紫色辅助色。所有应用弹窗的主背景、内容区和中性分区统一使用纯白色（`#ffffff`），不得使用奶油色、浅灰色或其他浅色底；用边框和间距区分内容。状态图标、选中标记与操作按钮保留必要的辨识度。避免新增孤立的色值与样式体系。
- 保留键盘操作、可访问名称和焦点提示。链接与文字按钮不使用下划线；长目录和重型内容继续采用分页、局部滚动或延迟渲染。

顶部导航只保留一个“设置”入口，较窄窗口下部分工具仅显示图标，并保留操作名称与悬停提示。播放器“目录”按钮在大窗口下切换左侧栏并调整播放区宽度，在窄窗口下打开或收起目录抽屉；切课关闭抽屉，不改变大窗口侧栏的展开选择。

播放器左侧“定制路线”默认平铺今日安排的视频，同一视频的多个学习或补学片段只列一次，保留路线序号；可通过“显示全部 / 只看今天”切换。当天已完成的视频保留在列表中，无安排时显示空状态；开始学习只进入当天未完成片段，搜索与观看状态筛选作用于当前显示范围。切换课程或跨天后恢复只看今天。

课程概览以课程路线为主栏，默认收起阶段课节；阶段行仅显示标题、路线序号范围与观看数量，接续阶段保留原有课节顺序并独立展开。路线与完整目录每页显示 12 节，搜索和状态筛选作用于全部课节。右栏展示今日学习、当前阶段和近七天投入，完整日历、阶段验收与时间安排通过详情入口打开；顶部不重复展示课程名称及统计。

AI 导学的定制路线采用单栏布局，已有路线时默认展示学习顺序和学习入口。调整要求与 AI 配置通过“调整路线”进入，完整计划、背景和对话默认收起；排期详情与路线说明按需展开。“课节安排”独立展示，每页 12 节，默认仅显示路线序号、课节标题和状态，展开单节后再显示推荐理由、前置关系与掌握控件。切换视图保留未提交的调整要求，路线调整继续保留预览、应用和撤销。AI 配置切换仅在生成或调整路线时显示；今日学习、知识地图和路线浏览不显示 AI 配置入口。“调整路线”与“开始学习 / 继续学习”使用相同尺寸。疑问回溯及笔记、练习、播放器的相关入口已移除；旧疑问记录保留在本地存储中，不再调用 AI，也不再加入今日任务。
