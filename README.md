# AI Player (智能伴学播放器)

> **定位**：本地优先的个人 AI 智能伴学工作台（AI Learning Copilot）。
> 核心目标：为上百集的技术大部头教程“做减法”，让长视频教程变成千人千面的“定制小课”，边看、边记、深度联动。

---

## 一、核心痛点与产品价值

- **痛点 1：大部头教程内容臃肿**。动辄几十上百集，很多基础知识用户已掌握，从头看浪费时间，盲目跳过又怕遗漏前置依赖。
- **痛点 2：视频与笔记割裂**。分屏记录效率低，笔记记了时间点无法直接跳回视频，复习时难以溯源。
- **痛点 3：视频信息检索极难**。只记得老师讲过某个知识点，无法像文档一样“Ctrl + F”全文检索。
- **痛点 4：遇到难点无从反馈**。听不懂时反复倒退，缺乏当前视频语境下的实时解答与代码/公式提取。

---

## 二、产品迭代路线图 (Roadmap)

```
[V1.0 核心基座]              [V2.0 AI 视听解析]          [V2.5 定制导学(核心)]         [V3.0 效率与生态]
播放器 + 双向笔记联动   ->   逐字稿 + OCR + 伴学答疑   ->   学情剪裁 + 动态智能排课   ->   无声跳过 + 外部同步
```

### 1. 阶段一：V1.0 基础联动版 (MVP)
> **目标**：跑通“本地视频播放 + 双向绑定笔记”的核心手感，解决分屏割裂。

- **本地视频与目录管理**：
  - 支持打开本地文件夹，递归解析视频列表并以树状展示。
  - 记录每集视频的观看进度（百分比、上次播放时间点）。
  - 基础播放器控制：倍速播放（0.5x ~ 3.0x）、快捷键快进/后退、音量控制。
- **双向联动 Markdown 笔记**：
  - 右侧内置 Markdown 编辑器，支持代码块高亮与数学公式。
  - **时间戳锚点**：快捷键一键插入当前秒级时间戳（如 `[12:35]`），点击直接驱动左侧视频跳回播放。
  - **一键截图入笔记**：快捷键截取当前视频帧，自动转为图片插入笔记并附带时间戳。
  - **本地存储**：笔记保存为本地 `.md` 文件，完全归属于用户本地。

---

### 2. 阶段二：V2.0 AI 视听数字化与伴学助手
> **目标**：将非结构化的音视频转化为可搜索、可交互的文本，降低学习心智负担。

- **语音转文字（ASR）与交互式逐字稿**：
  - 提取本地音频，生成字幕与完整**逐字稿（Transcript）**。
  - **交互点播**：点击逐字稿中的任意句子，视频直接跳转至对应发音处。
  - **视频内全文检索**：输入关键词（如“依赖注入”），一键定位所有提及的时间节点。
- **画面板书与代码 OCR 提取**：
  - 一键框选视频画面中的 PPT、黑板文字或代码片段，直接 OCR 转化为 Markdown 文本或格式化代码块。
- **视频伴学 AI 助理（In-Video Copilot）**：
  - **语境感知答疑**：用户提问时，AI 自动抓取当前播放点前后 3 分钟的字幕上下文进行针对性解释。
  - **划词解释**：在字幕或逐字稿中划选专业术语，一键让 AI 解释。
  - **单节智能小结**：一键生成当前课节的核心大纲与要点总结。

---

### 3. 阶段三：V2.5 AI 智能导学与定制路线（核心特色）
> **目标**：让 AI 私教根据用户水平为教程“做减法”，千人千面动态规划。

- **教程结构化知识图谱提取**：
  - 导入整个课程目录后，AI 分析所有文件标题和时长，归类知识板块（如：01~20 基础语法，21~40 数据库，41~70 SpringBoot）。
- **学情画像与对话式目标定制**：
  - 用户自然语言输入背景与目标（例如：“*我学过 Java 基础，只想速成 SpringBoot 开发项目，每天有 2 小时*”）。
- **前置知识依赖诊断（防踩坑机制）**：
  - 用户尝试跳过基础时，AI 进行依赖检查与风险提示：
    > *“提示：SpringBoot 深度依赖反射（Reflection）与注解。原教程第 18、19 节有详解，建议保留，其余 1~17 节为您跳过。”*
- **动态智能播放列表（Smart Playlist）**：
  - **三级状态打标**：【必修】、【选修/查漏】、【已跳过】。
  - **一键直达首课**：自动将起跑线定位到推荐的第一节课。
  - **视图一键切换**：支持在「完整目录」与「AI 定制路线（精简版）」之间自由切换。
- **学习节奏与排期预估**：
  - 根据精选后的总时长与用户每日时间投入，自动测算所需天数并生成学习里程碑。
- **自适应卡点回溯（Fallback Recommendation）**：
  - 学习高级课程遇到盲区（在笔记中提问或标记疑问），AI 自动匹配并推荐此前跳过的对应基础章节精准片段。

---

### 4. 阶段四：V3.0 效率进阶与生态互联
> **目标**：极致的播放效率提升与多端知识库互联。

- **智能跳过静音（Trim Silence）**：
  - 自动检测并加速/跳过讲师板书、思考、喝水等无声停顿片段。
- **外部知识库深度联动**：
  - 兼容 Obsidian / Logseq 知识库规范（直接管理本地 Markdown 文件夹）。
  - 支持一键导出排版完好的 HTML / PDF 讲义笔记。
- *(暂缓说明：复习卡片/Anki 自动生成功能已根据规划暂时挂起，后续按需启动)*

## 三、技术架构选型建议

| 层次 | 选型建议 | 说明 |
| :--- | :--- | :--- |
| **前端框架** | **Nuxt 4 + Vue 3 + TypeScript** | 项目当前基座，具备良好工程化与模块化生态 |
| **样式与组件** | Tailwind CSS / UnoCSS + Shadcn-vue | 现代、沉浸式、极简 Dark/Light 学习主题 |
| **播放器内核** | Video.js / Plyr / 原生 HTML5 Video | 支持自定义扩展控制条、时间戳图钉标记 |
| **笔记编辑器** | Milkdown / Tiptap / Vditor | 深度支持 Markdown、代码高亮、KaTeX 数学公式 |
| **本地文件访问** | File System Access API (现代浏览器) / Tauri (若打包桌面端) | 本地目录读写、笔记文件落盘 |
| **AI 引擎对接** | OpenAI 标准兼容 SDK | 支持对接云端 API（DeepSeek、OpenAI、通义等）或本地 Ollama / fast-whisper |

## 五、V1.0 实现说明

- **浏览器要求**：读写本地文件夹用的是 File System Access API，需要 Chrome / Edge 等 Chromium 内核浏览器；Safari、Firefox 目前不支持。
- **课程文件夹**：子文件夹作为章节，视频按自然顺序排序（`2.mp4` 排在 `10.mp4` 前面）。支持 mp4 / webm / mkv / mov 等容器，能否播放取决于浏览器解码器（mkv 里的 H.265 等播不了）。
- **笔记文件**：与视频同目录同名，如 `01-环境搭建.mp4` → `01-环境搭建.md`；截图放在 `01-环境搭建.assets/12-35.png`，笔记里用相对路径引用，Obsidian / Typora 可以直接打开。
- **时间戳**：笔记里的 `[12:35]` / `[1:02:03]` 会渲染成可点击的锚点，点击跳转视频；播放到对应片段时锚点变黄。文件里保存的仍是纯文本。
- **观看进度**：存在浏览器 localStorage（按课程隔离），最近打开的课程记录在 IndexedDB，下次一键恢复（浏览器会再确认一次文件夹权限）。
- **快捷键**：应用内按 `?` 查看。⌥T 插入时间戳、⌥S 截图入笔记、⌘S 立即保存；空格 / ← → / [ ] / M / F 控制播放（焦点在笔记里时不生效）。
- **样式**：Tailwind v4，设计令牌在 `app/styles/theme.css`（来自 DESIGN.md），入口 `app/styles/main.css`，编辑器主题覆盖在 `app/styles/editor.css`。
