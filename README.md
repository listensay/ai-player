# AI Player (智能伴学播放器)

> **定位**：本地优先的个人 AI 智能伴学工作台（AI Learning Copilot）。
> 核心目标：为上百集的技术大部头教程“做减法”，让长视频教程变成千人千面的“定制小课”，边看、边记、深度联动。

---

## 一、核心痛点与产品价值

- **痛点 1：大部头教程内容臃肿**。动辄几十上百集，很多基础知识用户已掌握，从头看浪费时间，盲目跳过又怕遗漏前置依赖。
- **痛点 2：视频与笔记割裂**。分屏记录效率低，笔记记了时间点无法直接跳回视频，复习时难以溯源。
- **痛点 3：遇到难点难以补基础**。学习高级课程时，不清楚遗漏了哪些前置知识，也难以找到值得回看的基础课节。

---

## 二、已实现功能

```
[V1.0 核心基座]                 [V2.5 定制导学]
播放器 + 双向笔记联动      ->    学情画像 + 定制路线 + 学习排期 + 卡点回溯
```

### 1. V1.0 基础联动版
> **目标**：跑通“本地视频播放 + 双向绑定笔记”的核心手感，解决分屏割裂。

- **本地视频与目录管理**：
  - 支持打开本地文件夹，递归解析视频列表并以树状展示。
  - 记录每集视频的观看进度（百分比、上次播放时间点）。
  - 基础播放器控制：倍速播放（0.5x ~ 3.0x）、快捷键快进/后退、音量控制。
- **双向联动 Markdown 笔记**：
  - 右侧内置 Markdown 编辑器，支持代码块高亮与数学公式。
  - **时间戳锚点**：快捷键一键插入当前秒级时间戳（如 `[12:35]`），点击直接驱动左侧视频跳回播放。
  - **一键截图入笔记**：快捷键截取当前视频帧，自动转为图片插入笔记并附带时间戳。
  - **本地存储**：笔记保存为本地 `.md` 文件，完全归属于用户本地。

---

### 2. V2.5 AI 智能导学与定制路线（核心特色）
> **目标**：让 AI 私教根据用户水平为教程“做减法”，千人千面动态规划。

- **教程结构化知识图谱提取**：
  - 导入课程目录并提交学习目标后，AI 根据文件标题和已读取的时长归类知识板块，展示知识点与前置依赖。
- **学情画像与对话式目标定制**：
  - 用户自然语言输入背景与目标（例如：“*我学过 Java 基础，只想速成 SpringBoot 开发项目，每天有 2 小时*”）。
- **前置知识依赖诊断（防踩坑机制）**：
  - 生成路线时自动保留关键前置课；手动跳过时，根据路线中的直接和间接依赖提示风险，支持保留当前安排、确认调整或补齐前置课。
- **动态智能播放列表（Smart Playlist）**：
  - **三级状态打标**：【必修】、【选修/查漏】、【已跳过】。
  - **一键直达首课**：自动将起跑线定位到推荐的第一节课。
  - **视图一键切换**：支持在「完整目录」与「AI 定制路线（精简版）」之间自由切换。
- **学习节奏与排期预估**：
  - 根据精选课节的剩余观看时长与每日时间投入，测算所需天数并生成学习里程碑；未知时长明确标为估算。
- **自适应卡点回溯（Fallback Recommendation）**：
  - 选中笔记中的疑问或标记疑问段落，点击“找基础”并提交后，AI 推荐此前跳过的相关基础课。有同名 SRT/VTT 字幕时可定位可验证的片段，否则从课首回看；支持返回原课位置。
- **知识掌握反馈**：按知识点标记已掌握、不确定或需要补学，即时更新路线，且不改变观看记录。
- **疑问清单与解决追踪**：保存问题、所属课节和提问时间，支持解决、重新打开及回看后的反馈。
- **今日学习安排**：按今日时间拆分待学课节、安排补学和疑问处理，支持短安排与完成勾选。
- **学习片段结束提醒**：连续播放到今日片段终点时显示提醒，可记笔记、处理疑问、做练习或确认完成。
- **学完一小练**：根据已有字幕、笔记或补充内容生成一道练习，保存作答与反馈，支持回看依据和主动标记掌握程度。

| 层次 | 当前实现 | 说明 |

## 五、V1.0 实现说明

- **浏览器要求**：读写本地文件夹用的是 File System Access API，需要 Chrome / Edge 等 Chromium 内核浏览器；Safari、Firefox 目前不支持。
- **课程文件夹**：子文件夹作为章节，视频按自然顺序排序（`2.mp4` 排在 `10.mp4` 前面）。支持 mp4 / webm / mkv / mov 等容器，能否播放取决于浏览器解码器（mkv 里的 H.265 等播不了）。
- **笔记文件**：与视频同目录同名，如 `01-环境搭建.mp4` → `01-环境搭建.md`；截图放在 `01-环境搭建.assets/12-35.png`，笔记里用相对路径引用，Obsidian / Typora 可以直接打开。
- **时间戳**：笔记里的 `[12:35]` / `[1:02:03]` 会渲染成可点击的锚点，点击跳转视频；播放到对应片段时锚点变黄。文件里保存的仍是纯文本。
- **观看进度**：存在浏览器 localStorage（按课程隔离），最近打开的课程记录在 IndexedDB，下次一键恢复（浏览器会再确认一次文件夹权限）。
- **快捷键**：应用内按 `?` 查看。⌥T 插入时间戳、⌥S 截图入笔记、⌘S 立即保存；空格 / ← → / [ ] / M / F 控制播放（焦点在笔记里时不生效）。
- **样式**：Tailwind v4，设计令牌在 `app/styles/theme.css`（来自 DESIGN.md），入口 `app/styles/main.css`，编辑器主题覆盖在 `app/styles/editor.css`。

## 六、V2.5 AI 智能导学与定制路线

V2.5 已接入播放器、目录和笔记。打开课程后，点击顶部 **AI 导学**，或目录里的 **AI 定制路线** 进入。

### 使用方式

1. 在 **AI 设置** 中填写 OpenAI 兼容服务的 API 基础地址（含 `/v1` 等前缀）、模型名称和密钥，然后保存。也支持完整的 `/chat/completions` 地址；本机 Ollama 可使用 `http://localhost:11434/v1` 和本机已有的模型名，未启用鉴权时密钥留空。
2. 在 **定制路线** 中描述已有基础、学习目标和每日时间，生成学情画像、知识板块与课程安排。可以继续补充目标，让 AI 调整已有路线。
3. AI 将所有课节标为 **必修 / 选修·查漏 / 已跳过**。关键前置课会自动保留；手动跳过时会提示直接和间接依赖，也可以一键补齐。知识地图可查看板块、知识点和课节依赖。
4. 点击 **一键开始首课**，从推荐的第一节未完成课开始。在 **AI 定制路线** 视图中，上一集、下一集及对应快捷键按依赖顺序导航；切到 **完整目录** 则按原始课程顺序。勾选“包含选修”可随时扩大路线。
5. 排期会随学习进度、课节状态、选修开关和每日时间更新。仅调整每天分钟数即可重新计算，无需再次调用 AI；时长按原速观看估算，未知时长会明确提示。
6. 在笔记里选中疑问，或写下带问号、“疑问”“不理解”“没听懂”的段落，点击 **找基础**。提交后会匹配当前课之前已跳过的基础课；同目录有同名 `.srt` / `.vtt` 字幕时可定位真实片段，回看后点击 **返回原课** 回到刚才的位置。没有可验证字幕或定位服务失败时，保留整节课程建议。

### 存储与服务要求

- **本地 SQLite 数据库持久化存储**：本项目使用 Node.js 原生 SQLite（`data/ai-player.db`），**全面替代并弃用了 LocalStorage 和 IndexedDB**。
- **持久化数据范围**：
  - 最近打开的课程（`recent_courses`）
  - 视频播放进度与完成状态（`video_progress`）
  - 每日学习打卡记录与学满目标判定（`check_ins`）
  - 课节笔记 Markdown 内容（`notes`）
  - 笔记截图与图片，采用 Base64 编码直接存入数据库（`note_images`）
  - AI 导学路线、知识点掌握度、卡点疑问与今日安排（`learning_guides`）
  - 课后微练习与反馈记录（`lesson_practices`）
  - 全局配置与 AI 服务密钥（`app_settings`，刷新页面或重启服务不丢失）
- 浏览器直接请求用户配置的服务，服务须允许本应用来源的跨域访问（CORS）。本机 Ollama 可通过 `OLLAMA_ORIGINS` 配置允许的应用地址；远程服务使用 HTTPS。
- 生成或调整路线发送标题、相对路径、时长、观看完成状态、导学对话、掌握标记及已记录的疑问和解决状态；回溯发送主动提交的疑问与相关字幕片段。小练习生成时发送选取的字幕、本课笔记文字和补充内容，提交作答时另发送题目与答案。不上传视频。单独记录反馈和调整今日安排不请求 AI。
- 知识依赖依据标题推断，需要结合实际内容核对。精确回溯依赖已有字幕，不会自动转写无字幕的视频。
- AI 请求支持取消、两分钟超时与错误提示。遗漏课程、虚构路径、循环依赖和截断结果不会替换现有路线。

### 验证

`npm test` 覆盖路线校验、前置依赖、播放顺序、排期、字幕解析、片段跨越检测、练习材料与引用校验、缓存恢复及兼容接口异常。`npm run test:e2e` 使用真实浏览器文件句柄与本地测试媒体，覆盖生成、调整、播放、笔记回溯、片段提醒、全屏、小练习作答、异常与取消、刷新恢复、课程隔离及窄屏布局；AI 响应由测试固定返回，不依赖真实密钥或产生接口费用。

浏览器测试为每项用例创建独立的临时常规配置目录，避免 Chromium 隐身上下文恢复 OPFS 句柄时的崩溃，运行后自动清理。默认使用 Playwright 配套 Chromium，也可通过 `PLAYWRIGHT_CHANNEL=chrome` 使用已安装的 Chrome。

## 七、学习反馈与今日安排

### 掌握程度

- 在 **定制路线** 的课节列表，或 **知识地图** 展开的知识点中标记 **已掌握 / 不确定 / 需要补学**；“未标记”表示尚未反馈。
- 一节课的全部知识点明确掌握后会从路线中略过，且可满足后续课程的前置依赖。任一知识点需要补学时，本课加入必修；部分掌握或不确定时保守查漏，关键前置课仍会保留。
- 观看完成、疑问解决与知识掌握各自独立，不根据观看比例或回看次数推断能力。可以修改或撤回标记；AI 重新规划会参考这些反馈，已有标记继续保留。

### 疑问清单

- 笔记中选中问题或写下疑问段落，点击 **记下疑问**，即可保存当前课节和时间点，无需配置 AI。点击 **找基础** 也会先记录疑问，再进入导学。
- 在 **AI 导学 → 卡点回溯** 查看清单，按待解决、已解决或全部筛选；点击提问位置可以返回原视频，点击 **继续处理** 可编辑疑问或重新查找基础课。
- 回看推荐基础课并返回原课后，可以反馈 **解决了 / 仍不理解**。“仍不理解”会将回看过的基础课知识点标为需要补学并加入路线；没有回看记录时仅保留疑问。解决后的疑问可以重新打开。
- 刷新后保留整课推荐；精确片段需再次查找，以重新校验当前字幕。修改疑问内容后清空旧推荐，避免沿用不相关的答案。

### 今日学习

- 从播放器上方的 **今日学习** 或导学中的同名标签进入。按路线依赖顺序，从未看完的位置安排课节；已看完但明确需要补学的课节从头安排复习。
- 长课可拆成当天预算内的片段；存在未解决疑问时优先为“仍不理解”的问题预留时间。点击事项或 **开始下一项** 可直达课节起点或对应疑问。
- **时间不多，短安排** 将今日预算缩短到最多 15 分钟；也可以直接填写今天可用分钟数。只影响当天，不改变每日学习时间。
- 看完片段或处理问题后勾选完成。完成事项不自动改变掌握程度；更新安排时保留已完成事项并扣除其用时，避免重复分配。实际进度变化后可点击 **按最新进度更新**。
- 今日安排和完成勾选支持刷新恢复。按浏览器本地日期切换到新的一天，恢复每日预算；时间估算以原速观看为准。

### 学习片段结束提醒

- 当前视频匹配今日未完成片段时，播放器下方显示本次范围；从 **今日学习 → 开始下一项** 可从片段起点播放。
- 正常播放跨越终点会显示提醒，默认不暂停，全屏也可见。拖动进度、时间戳跳转、暂停或切课不会误触发；同一片段本次打开页面只提醒一次，从今日安排主动重新开始可再次提醒。
- 提醒中可 **检验一下**、**记笔记**、**处理疑问**、**标记片段完成** 或收起提醒。进入笔记、疑问或练习时暂停播放；记笔记会插入片段终点时间戳。标记片段完成只更新今日事项，不改变知识掌握程度。
- 视频实际时长短于估算范围时，以真实结束位置提醒。处理疑问事项不按视频计时提醒。

### 学完一小练

- 点击播放器下方或播放结束画面的 **学完一小练**，也可在片段提醒中点击 **检验一下**，按该片段出题。无需先生成学习路线，使用导学中保存的 AI 服务设置。
- 打开时只读取本地材料；点击生成才发送选取内容。支持同名 `.srt` / `.vtt` 字幕、本课笔记（含尚未保存的文字）及手动补充内容，生成一道解释题、代码题或小任务。代码仅供书面作答，不执行。
- 片段练习只选取与范围相交的字幕，保留字幕原始起止时间；整课笔记仅作为补充背景。材料合计最多 12000 字，其中笔记和补充内容各最多 4000 字，可展开预览实际发送内容。不会只凭课程标题出题，材料不足时提示补充。
- 先写答案，再提交查看正确部分、遗漏点及下一步建议。参考答案默认折叠，依据中的字幕时间可点击回看。AI 引用不存在的材料、格式错误、请求失败或取消时，保留已有练习与草稿。
- AI 反馈不会自动更改掌握程度；答题后可主动为本题知识点标记 **已掌握 / 不确定 / 需要补学**，也可撤回。已有路线会据此更新，未生成路线时也会保存标记供后续规划使用。
- 每门课程在当前浏览器保留最近 20 道练习、作答草稿及每题最多 3 次反馈；重新打开可继续作答。关闭练习或切换课程会取消请求，密钥不会写入记录。清除浏览器数据会删除这些记录。
