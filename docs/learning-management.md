# 学习管理扩展

入口为首页「待加强」和「学习管理」。界面沿用 `DESIGN.md` 的暖纸色、圆角卡片与胶囊按钮；学习计算、状态协调、原生读写分别位于 utils、composables 与 Tauri，遵循 `CONTRIBUTING.md`。

## 功能

| 入口         | 行为                                                                                                                                                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 抗遗忘复习   | 保留错题与薄弱项，支持按课程、掌握度、知识分类筛选、回看原片段和针对性补练；不再显示复习闪卡。                                                                                                                          |
| 错题与薄弱项 | 汇总课后练习、今日巩固与标记待复习的概念，按课程、知识分类、掌握度筛选；沿用现有 AI 练习流程生成 3 道变式题。                                                                                                           |
| 成长与复盘   | 比较过去七天的原定预算、任务完成和实际投入；提供减量或周末分担方案、AI 建议、日期预览与撤销。                                                                                                                           |
| 连续学习     | 每月两次防断卡能量，可保护昨天；完成过去 30 天的积压安排后可补卡。保护记录独立保存，实际学习时长保持原值。                                                                                                              |
| 实践作品     | 作品可绑定课程或阶段，支持本地绝对路径、在线 Demo、说明与截图。阶段验收完成后作品自动归档，也可手动验收。                                                                                                               |
| 学习契约     | 为课程或阶段记录每日投入、截止日期和交付目标，支持修改已有契约。整门课程的目标手动填写，阶段默认使用实践目标，不使用路线摘要。完成必修、阶段验收及契约交付后，成果报告自动成为结课证书；支持 Markdown 和高清 PNG 导出。 |
| 心流时段     | 每节视频课结束并关闭课后练习后，一次点击记录四种学习状态；每课仅提示一次，暂停、番茄钟结束和重播不重复提示。按课程和小时查看顺畅、吃力及疲劳情况。                                                                      |
| 专注伴学     | 全屏番茄钟期间 Karen 收起气泡、保留倒计时和进度。可选择在专注开始时运行指定 macOS 快捷指令。                                                                                                                            |
| 学习日历     | 按真实学习计划连续生成未来 1–90 天日程，保留课节跳转与预估时长，多课程顺序安排。提供 ICS 导出与本机 WebCal 订阅。                                                                                                       |

## 复习与持久化

采用固定间隔 SRS（1、2、4、7、15、30 天），不声称实现 FSRS。复习评价按本地日期推进；同一张卡当天只能评价一次；每日队列完成后亲密度增加 5，重启和重复提交不会重复领奖。暂停、归档课程保留历史，但不加入今日队列。

新增 `learning-management:v1` 设置记录，首次读取旧库时使用默认值；未知版本和损坏记录报错并暂停覆盖。原笔记、练习、导学和打卡表继续使用原结构。`learning-sources` 只读取相关材料，不返回其他设置或服务密钥。卡片使用来源稳定标识，修改笔记不会重置已记录的间隔。

减负仅写入未来日期预算，保留原定预算快照、实际学习记录和课程顺序。未打开课程的调整在事务中比较原计划并保存撤销记录；当前课程复用原排期和撤销流程。首页恢复计划时保留原 `createdAt`，避免计划读取本身制造版本变化。

## 外部连接

- Apple 日历：使用 `http://127.0.0.1` 本机订阅地址，并直接交给 Apple 日历打开，避免 `webcal://` 被升级为本机服务不支持的 HTTPS。首次订阅可能提示连接不安全，确认地址是 `127.0.0.1` 后可继续，位置请选择「在我的 Mac 上」。本机订阅地址在应用运行期间可访问，端口与随机路径持久化。服务只监听 `127.0.0.1`；重排和学习记录变化后更新内容。应用退出时不能刷新，日历已缓存事件仍由日历软件保留。
- Google 日历：使用 ICS 文件导入。本次没有部署公网订阅服务，Google 的服务器不能访问本机 WebCal 地址。
- Notion：播放器右侧直接使用原生网页视图，每节课可绑定自己的页面。正文在 Notion 内编辑和保存。旧的集成密钥、Markdown 文档块双向同步入口已移除。详见 [Notion 笔记](../README.md#notion-笔记)。
- macOS Focus：先在系统「快捷指令」中创建启用专注模式的指令，再在学习偏好填写其名称。应用按名称调用 `shortcuts run`，不修改系统专注配置；未配置时不调用。

## 验证

`tests/learningManagement.test.mjs` 覆盖旧库默认值与损坏记录、复习间隔、重复领奖、保存失败、并发写入、错题来源、补卡条件、减负的历史保护、日历推进和 UTF-8 折行、知识库三方合并、成果验收与心流统计。Rust 测试覆盖学习材料聚合范围、笔记条件写入、日历私有路径、文件原子更新、符号链接越界和播放器链接校验。

独立桌面样例：

```sh
node scripts/prepare-learning-management-fixture.mjs
npm run tauri -- build --debug --bundles app --config tests/fixtures/learning-management.json
```

应用名称 **AI Player Learning Check**，标识 `app.aiplayer.learning-management-check`。脚本遇到已有测试数据库会拒绝覆盖。样例使用合成课程、错题、笔记和心流记录，不配置外部服务密钥。实际回归情况记录在 `docs/ui-regression.md`。

真实 AI 服务、Notion 账号、系统快捷指令和外部日历客户端仍需使用各自配置进行集成验收；本地文件同步和日历服务可独立验证。
