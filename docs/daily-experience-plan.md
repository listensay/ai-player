# 日常学习体验功能

日期：2026-09-26  
状态：本轮功能已实现，验证记录见文末。

## 本轮范围

完成今日首页、弹性学习计划、进度总览和周回顾。根据用户最新要求，备份与恢复、换机迁移、自动备份暂不实现。

沿用 Tauri 桌面架构、SQLite、Vuetify 和现有学习计算逻辑。首页、排期调整和统计无需配置 AI；已有 AI 路线、笔记、练习与转写功能继续使用原入口。

## 1. 今日首页

已有课程时默认进入学习首页；首次使用保留打开课程的引导。

- 继续学习：显示最近课程、课节和播放位置，点击后恢复播放。
- 今日安排：按课程分组展示视频、实践、疑问及巩固入口。可直接播放计划片段，进入记录或调整计划。
- 今日投入：汇总有效观看与已记录实践。总预算超过每日可用时间时提示差额，不自动在课程之间分配时间。
- 我的课程：搜索、分页、置顶、进行中/暂停/归档筛选；暂停与归档保留记录，可恢复。

课程库独立于最近打开列表，不受 20 条上限影响。首页只读课程记录，不主动扫描视频或发起 AI 请求。单门课程读取失败时单独提示，汇总不将错误记录当成零进度。

主要文件：`app/components/LearningHome.vue`、`app/composables/useLearningHome.ts`、`app/utils/learningHome.ts`、`app/composables/useCourseStore.ts`。

## 2. 弹性学习计划

入口位于课程概览和今日安排的“设置学习计划 / 调整计划”。无 AI 路线时可按原课节顺序生成本地计划。

| 操作 | 行为 |
| --- | --- |
| 每周安排 | 选择学习日，配置工作日与周末的观看、编码、项目和复习预算 |
| 调整今天 | 临时修改各类预算，或一键设为休息日 |
| 暂停学习 | 选择恢复日期或手动恢复，暂停期间不新增任务 |
| 恢复学习 | 选择顺延阶段与结束日期，或保留截止日期并限制每日总投入 |
| 调整剩余计划 | 按指定天数顺延，或在每日上限内重新分配观看时间 |

每次修改先预览今日剩余任务、未来七天预算、预计视频完成日期、计划结束日期和阶段变化，应用后生效。保留截止日期时若容量不足，显示缺口并阻止应用。

### 规则

- 课程暂停/归档以及计划暂停优先于旧的单日观看覆盖值；日期例外优先于每周预算。已有阶段专属工作日预算继续生效。
- 定时暂停到期后恢复原排期，可另行顺延；手动恢复可按实际暂停天数顺延。
- 保留已完成任务、实际观看、实践投入、验收证据与知识掌握，只调整剩余安排。
- 休息后恢复预算时，恢复未完成实践的目标，不把实际投入当成新的永久目标。
- 顺延不改变课节前置关系，阶段变化独立显示。
- 当天已完成的视频占用当天预算，预计完成日期和截止日期容量计算避免重复分配。
- 撤销只恢复安排，保留调整后新增的学习记录；重启后仍可撤销。
- 未达标的休息日清除旧目标，已达成的打卡保持原记录。

主要文件：`app/components/PlanAdjustment.vue`、`app/utils/planAdjustment.ts`、`app/utils/studyProgram.ts`、`app/composables/useLearningGuide.ts`、`app/utils/dailyPlan.ts`。

## 3. 进度与周回顾

首页提供可切换周的紧凑图表，点击日期查看各课程实际投入和已保存任务。课程卡片显示观看进度、当前阶段与计划阶段偏差、预计视频结束日期；通过安排入口进入计划调整。

### 统计规则

- 首页与课程内使用同一份每日计划计算，实际观看以有效经过时间计，实践按已有记录计入。
- 多课程先累计秒数，再换算展示分钟，避免逐门舍入造成汇总误差。
- 预计观看结束按 1 倍速计算；视频时长未知时标记估算。
- 观看完成、任务完成、知识掌握与阶段验收各自记录，不计算综合分数。
- 每日快照保存最初预算、当前预算、稳定任务标识及状态；较旧快照不能覆盖新快照。
- 旧数据没有历史计划快照时，只显示实际投入和已有记录，不补造历史完成率。
- 暂停或归档课程继续参与历史投入统计。

新增存储：`course_library`、`daily_plan_snapshots`。每周规则、日期例外与暂停状态保存在现有计划结构，可撤销安排保存在现有实践记录中。
