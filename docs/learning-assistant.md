# 随堂助教与主动学习

## 入口

在播放器右侧点击「助教」，或按 `Alt/Option + A` 暂停并提问。普通暂停不会自动打开助教或发送请求。笔记工具栏「AI 整理」会读取当前选区；Playbo 右键菜单「问问 Playbo」打开同一个助教，桌面挂件同时唤回课程窗口。

所有生成均使用现有 AI 设置。未配置服务、缺少材料、模型输出无效或网络失败时显示错误，可重试或取消。退出播放器、切换课程／课节、切换模型时会取消在途生成，晚到的结果不会写入另一课节。

## 功能

- **随堂问答**：固定提问时刻，读取前后各 90 秒的相交字幕与知识点。提供通俗解释、原理与代码问题快捷指令。最近四轮对话作为会话历史发送，历史回答不当作课程证据。回答引用只能指向本次材料中的来源，点击可回看；插入笔记使用提问时刻而非回答完成时刻。
- **笔记 AI**：选区或粘贴的文字可以生成技术卡片、对比表格、边界条件和注释示例；留空则整理当前位置字幕。先预览，再追加或确认替换选区。替换前比较完整文档快照，原文有变化就拒绝覆盖。编辑使用正常 Milkdown 事务，可撤销。生成内容中的图片节点不会直接写入笔记，避免意外加载外部资源。
- **知识脑图**：按整课可用材料生成有来源的单根树。概念支持折叠／展开与时间戳跳转，可将 Mermaid 源码存入笔记。Mermaid 标识符由本地生成，不执行模型提供的脚本或点击指令。
- **记忆闪卡**：生成 3–5 张问答卡片，支持翻面、编辑并确认加入已有抗遗忘队列。同课节同问题去重，不覆盖原卡复习进度；通过「学习管理 → 抗遗忘复习」继续复习。本版使用应用内队列，没有增加 `.apkg` 导出。
- **费曼对练**：支持「小白新手」「技术面试官」角色、文字解释、反馈评分、盲区提示和连续追问。评分仅作本轮学习参考，不自动修改掌握度。每轮结果可保存至笔记；本版不采集麦克风或提供语音输入。
- **画面识别**：截取当前画面后只在本地预览，单独确认目标服务与模型后才发送这一张图片。识别代码、板书和 LaTeX 公式，并提示模糊内容。截图上限 8MB；模型需支持图片。结果可以写入笔记或显式载入独立 Monaco 练习台；JavaScript 可手动在 QuickJS Worker 沙箱运行（无网络、文件、DOM 或 Tauri 权限，有时间和内存限制），其他语言可编辑保存。存在当前编程题时，另行确认才能替换该题草稿，不自动运行。
- **精华跳读**：分析字幕，标记核心讲解、演示练习与过渡／闲聊，进度条显示对应色带。允许人工纠正分类；默认不跳读，明确开启后只跳过已标记的过渡片段，保留未知区域、练习与视频结尾。可撤销上次跳过并关闭跳读。跳转仍使用播放器现有 seek 事件链，不将播放位移计算为实际学习时长。
- **Playbo 课程反馈**：课节完成时使用实际完成课节的名称生成简短鼓励，右键问答与主界面共用上下文；不额外后台请求 AI。

## 数据与隐私边界

- 不上传视频文件。普通「截图」仍只写入本地笔记，只有「画面识别」的单独确认会上传截图。
- 问答、脑图、闪卡和费曼对练默认不附带笔记；勾选后可发送当前已加载的笔记，包括未保存文字。笔记 AI 发送用户选中或粘贴的文字。发送前可展开课程材料预览。
- 截图授权绑定当前画面及 AI 配置，重新截图、丢弃截图或切换服务／模型会清除授权。
- 生成预览、会话、截图和片段标记只在当前课节会话保留；切课后清空。需要长期保存的回答、脑图、代码、对练反馈应加入笔记，闪卡应加入复习队列。截图临时 URL 会释放。
- 单次课程证据最多 60,000 字，单条最多 8,000 字，附带笔记最多 12,000 字。较长材料会截断并在预览和结果提示中明确说明，不能视为全课分析。
- AI 标记、识别与评分均可能有误；执行代码、覆盖草稿、替换笔记及加入队列都需要用户动作。

## 验证

`node --test tests/learningAssistant*.test.mjs` 覆盖上下文边界、材料长度、无效来源、脑图循环、卡片去重与调度兼容、评分校验、片段边界、取消／切课竞态、截图授权及笔记跨课节隔离。已有播放器、笔记、桌宠、AI 协议与全量回归测试继续适用。

开发验证使用独立内存课程和模拟 AI 返回，不调用用户配置的真实服务，不发送真实截图；真实视觉模型的识别质量取决于所选服务。
