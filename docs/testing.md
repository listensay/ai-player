# 学习链路验证

运行 `npm run check` 执行 Node 24 测试、Vue/TypeScript 检查和前端构建。
运行 `node scripts/desktop-runtime.mjs` 后，可执行 `cargo test --manifest-path src-tauri/Cargo.toml`。
CI 在 macOS 上运行这些检查并构建桌面应用，Cargo 缓存目录使用 runner 临时目录，不依赖本机 SSD 挂载。

自动化测试覆盖：

- `learningFlows.test.mjs`：使用项目 SQLite schema、临时数据库文件、Markdown 副本、生产数据库客户端和 Vue Router，验证读取失败、空笔记、保存中继续编辑、切课等待、失败阻止离开、重开数据库恢复，以及 AI 断点恢复。
- `noteLoading.test.mjs`：验证编辑器模块与实例的异步就绪、失败重试、课节切换丢弃旧操作、截图时间点及保存反馈。
- `knowledge.test.mjs`：验证知识点与多批练习的真实状态流程、失败续跑、整组应用和最终保存重试。
- `transcriptJobs.test.mjs`：验证分批校对失败时原字幕不变，续跑与文件保存重试不重复调用模型。
- `learningFlows.test.mjs` 还覆盖进度读取失败、在途修改、自动重试、重新打开数据库，以及短图片引用与旧内嵌图片兼容。
- `transcriptAi.test.mjs`、`transcriptJobs.test.mjs` 和 `retainedCache.test.mjs`：验证漏句、重复 ID、旧批次重校验、缓存淘汰与当前课节和失败任务保护。
- `runtimeCache.test.mjs`：使用临时目录验证增量同步、输出修复、过期文件清理、执行权限和失败后重试。
- Rust 数据库测试覆盖按课节和文件名读取单张图片、只清理过期已完成 AI 批次，以及保留未完成任务和其他设置。

桌面手动回归使用隔离的应用标识，避免混入日常学习记录：

```sh
npm run tauri -- dev --config tests/fixtures/desktop-test.json
```

在临时目录准备两个短视频与同名字幕，导入这门测试课程：

1. 进入播放器，确认右侧依次为笔记、知识点、逐字稿，默认显示笔记，首次加载完成后可编辑；切换页签后草稿保留，切换课节后重新选中笔记。
2. 输入笔记，立即切换第二课，再返回第一课；确认内容保存。关闭并重开测试应用，确认内容仍在。
3. 笔记未打开时使用时间戳、截图快捷键和逐字稿引用，确认编辑器加载后仅插入一次，内容属于发起操作时的课节。
4. 自动化故障注入覆盖数据库与副本不可写、模型中断、取消后的迟到响应；手动回归无需破坏数据库或修改真实课程权限。

性能比较以构建输出中的 PlayerPage 块为依据；NoteEditor 是单独按需加载的大块，拆分不代表应用总包体积同比减少。

核心流程已拆出 `useNoteSession`（笔记读写队列）、`useNoteWorkspace`（笔记操作与课节校验）、`useWorkspaceLifecycle`（导航与关闭保护）、`useGuidePersistence`（导学持久化）和 `aiBatchTask`（批次进度）。后续拆分可沿这些边界补充行为测试。

导学业务进一步拆为 `useGuideScheduling`、`useGuideMastery` 和 `useGuideAi`。`guidePersistence.test.mjs` 沿用原有排期应用、撤销和记录保留测试，并覆盖旧疑问记录保留但不参与排期，以及切换 AI 配置后的迟到响应隔离。

2026-09-28 本地验证：175 项 Node 测试、24 项 Rust 测试、类型检查、前端构建及 macOS 调试应用打包通过。在隔离的 Tauri 应用中验证了首次快捷键加载、输入后立即切课、文字和旧 Base64 图片恢复、新截图以路径保存并在重启后显示，以及退出前写入播放进度。运行环境连续准备时，第二次复用全部 414 个文件。AI 故障与续跑通过受控模型边界测试，未调用外部付费服务；新增 CI 尚未在远端运行。

整课总结回归：`knowledge.test.mjs` 覆盖长课全部材料进入主题合并、超长材料逐层归纳、漏引或伪造材料被拒绝、合并失败只续跑未完成步骤，以及旧片段缓存成功升级后才替换。`dailyExperience.test.mjs` 验证旧疑问不再占用视频预算，已完成视频仍保留。隔离桌面应用使用本地样例验证了整课概览与主题要点布局、移除总结回看按钮、导学仅三个页签、路线操作等宽等高，以及笔记和练习不再出现疑问入口；练习的掌握度记录仍可使用。

桌宠点击回归：Rust 测试覆盖透明留白、圆角、不同缩放与负坐标屏幕；`companionHitRegions.test.mjs` 验证隐藏控件不占用点击区域，`companion-interactions.test.mjs` 验证窗口失焦关闭菜单及监听清理。原生窗口需验证留白和气泡下方的其他窗口可点击、机器人单击和拖动、右键菜单与关闭重开。

桌宠与笔记默认页签更新后：177 项 Node 测试、28 项 Rust 测试、类型检查、前端构建和 macOS 调试应用打包通过。隔离桌面应用确认笔记排第一且默认选中、切课后恢复笔记、回复气泡居中下移，以及桌宠单击、右键菜单和关闭重开。原生诊断确认透明区进入忽略鼠标事件状态并记录窗口移动；自动化不能独立证明其他应用收到了物理鼠标点击，这一点仍需实际桌面操作确认。混合屏幕缩放由几何测试覆盖。
