# AFFiNE 本地工作区

目标是把 AI Player 扩展为课程、笔记、白板和学习助手共用的桌面学习工具。首页的“笔记”进入独立工作区，不要求先打开课程。播放器右侧的“笔记”使用同一个工作区，首次打开课节时创建对应文档，切课时恢复对应文档；“打开笔记工作区”进入完整整理界面。

## 版本与构建

基于 AFFiNE `v0.27.4`，固定提交 `b4c8548c09da21b2898443559a5b846f0ccf5dd8`。完整前端保留文档、白板、数据库视图、文件夹、标签、收藏、精选、日记、双向链接、搜索、附件、模板和回收站等模块。改动以 `integrations/affine/local.patch` 维护，不依赖在线 AFFiNE 页面。

主项目使用 Node 24；AFFiNE 上游构建使用 Node 22。先设置 `AFFINE_NODE` 为 Node 22 可执行文件的完整路径，再执行 `npm run notes:build`。`AFFINE_SOURCE_DIR` 可指定外置盘上的专用源码目录；默认是 `.cache/affine-source`。初次构建下载固定版本并安装上游锁定的依赖，后续复用依赖。构建脚本会校验提交号、应用补丁、编译上游工作区并复制到 `src-tauri/affine/`。

此目录是生成资源，不加入主前端的类型检查和格式检查，也不提交编译产物。其来源、源码补丁和资产 SHA-256 写入构建清单。随后按主项目流程运行检查与 Tauri 构建。

## 本机存储与隔离

工作区使用 AFFiNE 的 IndexedDB 文档、附件和索引存储。AI 对话另存于本机 IndexedDB。macOS 使用本应用的持久 WebKit 数据目录；其他桌面平台使用应用数据目录中的 `affine-profile`。它们与 Safari、Chrome 和 Notion 面板的数据分别保存。

嵌入的网页由应用自己的只读资源服务提供，只监听 `127.0.0.1`，不提供笔记读写 HTTP 接口。首次运行选定的端口保存为应用数据目录中的 `affine-port`；后续启动保留同一地址，避免切换网页存储空间。端口冲突时报告错误，不自动换地址而让笔记看起来丢失。备份和迁移本机网页存储时应同时保留该端口记录。

仅注册本机工作区提供者，取消云同步存储、账号入口、在线分享与遥测。独立笔记视图只获得笔记 AI 请求、取消和导出等明确权限，文件保存仍通过原生对话框选定位置。AI 密钥不传给 AFFiNE；主窗口读取当前模型配置并完成请求。只有用户发起的 AI 操作才调用模型服务，材料可以包含所选文档、文字附件和明确添加的图片。

AFFiNE 的依赖需要动态脚本执行，因此只有笔记视图允许 `unsafe-eval`；主窗口原有内容安全策略不变。笔记视图仍限制脚本来源、网络连接、页面跳转和原生命令。使用同样限制的 Chromium 对照测试复现了此前的初始化卡顿，允许所需脚本执行能力后，桌面工作区恢复正常。

## 导入导出与 AI 范围

文档工具栏提供导出；设置的存储页提供文档与附件的工作区快照导出，保存由原生文件对话框完成。快照沿用 AFFiNE BlockSuite ZIP 格式，不能视为操作系统数据目录的完整镜像；模型配置与独立 AI 对话不包含在该文档快照中。任何附件读取失败都会使快照导出失败，避免把缺失附件的压缩包标记为完成。单次导出上限为 128 MB。

文字问答、总结、翻译、改写和代码解释等操作复用主程序的 OpenAI 兼容或 Anthropic 配置。对话记录保留在本机，取消请求不会写入迟到回答。图片理解使用同一模型的图像输入能力；文字/Markdown/CSV/JSON 和 PNG/JPEG/WebP 可作为材料。图像生成需要独立的图像输出接口，现有聊天配置不能直接替代 AFFiNE 的云端生图服务。云协作、在线发布、企业管理及云端订阅能力不属于本机免登录版本。

## 验证

macOS 多网页视图重叠时，底层主网页仍会收到鼠标移动并覆盖笔记的手形或文本指针（[Wry #1763](https://github.com/tauri-apps/wry/issues/1763)）。实际事件由 WebKit 的 `WKMouseTrackingObserver` 接收，会绕过 `WKWebView.mouseMoved:`；先前只过滤网页视图方法的版本仍会闪烁。`webview_cursor_macos.rs` 在主网页的 tracking-area observer 上过滤鼠标移动和进入事件，并按上次命中状态转发离开事件。AppKit 原生命中检测决定最上层视图，笔记隐藏后主网页自然恢复处理。其他 observer 保持原行为，关联状态弱引用网页，避免循环持有；不改变任何实例类型，避免 macOS 26 全屏切换时的 AppKit 计算属性崩溃。该兼容处理依赖 WebKit 私有类，安装前检查类名及方法是否存在。

桌面回归在笔记四角附近和中心检查原生指针归属及 observer 关联，同时确认主工具栏仍能处理指针；覆盖课节面板、独立笔记工作区、调整宽度、弹窗、侧栏、标签、全屏、首页和重启。此检查验证原生命中分配，不等同于对系统指针连续画面的逐帧采集。独立测试包可通过 `AI_PLAYER_CURSOR_TRACE=1` 记录实际鼠标事件是否被过滤及原生指针设置；诊断代码不进入正式包。2026-10-16 用户在测试窗口的“全部”按钮上实际移动鼠标后确认不再频繁切换，同时日志记录到覆盖区域的主网页移动事件被拦截。

`npm run notes:test` 检查本地 AI 对话存储、跨工作区隔离、取消和迟到响应，以及图片材料传递；需要先准备上游源码与依赖。主程序检查继续覆盖模型协议与播放器导航。独立桌面应用配置为 `tests/fixtures/affine-check.json`，应用标识 `app.aiplayer.affine-check`，不访问正式应用数据库。

2026-10-16 验收：462 项前端测试、55 项 Rust 测试、3 项笔记 AI 专项测试、格式、静态检查、类型检查和构建通过。独立桌面回归两次启动验证课节文档创建、切课隔离、视图位置、弹窗/侧栏/全屏隐藏、原生命令隔离和重启恢复。首次创建本机文档等待本机读写完成，不再等待只有接收已有文档更新才会设置的就绪状态；工作区备份使用相同的本机读写等待方式。

真实 macOS 窗口确认中文粘贴编辑、文档/白板切换、Markdown 导出、带附件的工作区快照导出与重新导入，以及刚新建文档的立即备份。取消保存对话框不提示成功或失败。使用本机模拟模型验证笔记 AI 复用主程序配置并收到回复，退出重启后能从历史列表恢复问答；未调用外部付费模型，未建立中文输入法候选词组合的测试覆盖。

日志与样例位于 `.cache/affine-final-check.log`、`.cache/affine-final-rust.log`、`.cache/affine-final-notes-tests.log`、`.cache/affine-desktop-continued.log` 和 `.cache/affine-qa/`。其他验收与安装记录见 `docs/ui-regression.md`。第三方许可见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。
